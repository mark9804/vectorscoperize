# Vectorscoperize

Vectorscoperize is a macOS menu bar app that analyzes a selected screen region using a BT.709 Cb/Cr vectorscope and RGB parade.

## Features

- Switch between vectorscope and RGB parade view modes
- Capture a specific region of the display
- Reopen the app from Finder or Spotlight to restore the scopes, or select a region if capture is not running

## Scope coordinates

The capture stream is 8-bit sRGB. The vectorscope applies the BT.709 color-difference matrix to these encoded RGB values:

```text
Y' = 0.2126 R' + 0.7152 G' + 0.0722 B'
Cb = (B' - Y') / 1.8556
Cr = (R' - Y') / 1.5748
```

Horizontal position is `2 Cb`; vertical position is `-2 Cr` in texture coordinates. The circle radius represents an axis excursion of 0.5 Cb/Cr, not a circular gamut boundary. Six target boxes are computed from 75% RGB color bars using the same matrix as the live trace. Matrix reference: [ITU-R BT.709-6](https://www.itu.int/rec/R-REC-BT.709-6-201506-I).

## Build and check

With Xcode selected, run `bash bundle.sh` to create `Vectorscoperize.app`. Run `bash scripts/check.sh` to check CPU/Metal color-bar coordinates, window reopening, and mode switching after an idle frame without a test framework.

`bundle.sh` forwards arguments to `swift build`. For Command Line Tools with Swift 6.4 and an installed macOS 26.5 SDK:

```sh
bash bundle.sh --build-system native --sdk /Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk
bash scripts/check.sh -sdk /Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk
```

## Usage

- Download the latest release from [releases](https://github.com/zhaoluchen/vectorscoperize/releases/latest).
- Unzip the release file, drag to Applications folder.
- Remove quarantine attribute from the app by running `xattr -cr /Applications/Vectorscoperize.app`.
- Start the app. The app will prompt you to select a region of the display you want to capture. After you select a region, the application window will appear.

## Keyboard Shortcuts

When the application window is focused or the menubar icon is clicked, you can use the following keyboard shortcuts:

- <kbd>⌘</kbd> + <kbd>S</kbd> to (re-)select a region of the display
- <kbd>⌘</kbd> + <kbd>1</kbd> to switch to vectorscope view mode
- <kbd>⌘</kbd> + <kbd>2</kbd> to switch to RGB parade view mode
- <kbd>⌘</kbd> + <kbd>V</kbd> to show/hide the scopes
- <kbd>⌘</kbd> + <kbd>Q</kbd> to quit the app
